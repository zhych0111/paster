## Why

macOS 自带剪贴板只能访问最近一次复制的内容，查找旧内容、重复粘贴和管理常用片段都不方便。开发一款轻量、以本地数据为主的剪贴板工具，让这些高频操作更快，同时让用户清楚地控制哪些内容会被保存。

## What Changes

- 提供常驻菜单栏的 macOS 应用，自动记录受支持的剪贴板内容，并在历史列表中预览、去重和管理。
- 提供全局快捷键打开历史，支持搜索、键盘选择、重新复制或粘贴历史项，以及固定常用内容。
- 提供暂停记录、清空历史、保留期限和应用排除设置，降低敏感内容被意外保存的风险。
- 默认将历史保存在本机；首版不依赖账户或云端同步。

## Capabilities

### New Capabilities

- `clipboard-capture`: 识别并记录受支持的复制内容，处理重复项，并生成可浏览的历史。
- `history-library`: 浏览、搜索、固定和删除历史项，管理常用内容。
- `quick-paste`: 通过菜单栏或全局快捷键快速选取历史项并再次使用。
- `privacy-controls`: 控制记录开关、应用排除、历史保留和数据清除。

### Modified Capabilities

无。当前项目没有既有规格。

## Impact

- 新增 macOS 桌面应用、菜单栏入口、历史界面、快捷键及设置界面。
- 涉及系统剪贴板读取、前台应用识别、本地持久化，以及重新粘贴所需的系统权限处理。
- 历史内容只在本机保存；具体支持的内容类型、存储格式和权限方案将在后续规格与设计中确定。
